## 🚀 What I Do

**Minecraft Plugin Development**
Plugin per **PaperMC** e proxy **Velocity**: gestione dei giocatori, integrazioni con
sistemi di autenticazione (nLogin) e anti-bot (Sonar), tool interni per il network.

**Game Server Infrastructure**
Gestione di server di gioco su **Pterodactyl** e VPS Linux: deploy, configurazione,
backup, allocazioni e monitoraggio dei nodi.

**Localization & Server Tooling**
Traduzione e adattamento di plugin di terze parti, script di automazione e
utility per la manutenzione quotidiana dei server.

**Windows Desktop Tools & Audio DSP**
Applicazioni **C# / .NET** distribuite come eseguibile singolo — per esempio
[Mic Flow](https://github.com/il-russo/MicMonitor): monitoraggio del microfono in
tempo reale via **WASAPI shared**, senza driver virtuali, con FFT a 1024 punti,
VU stereo true-peak, noise gate e limiter. Interfaccia HTML incorporata e
renderizzata da **WebView2**, con scaling per monitor gestito a mano e una
**modalità prestazioni** che sospende metering e analisi lasciando intatto il
percorso audio, per chi gioca mentre ascolta.
